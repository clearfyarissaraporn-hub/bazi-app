# ปาจื้อ ฉัน / โลก

เว็บแอปดูดวงปาจื้อ (八字) พื้นฐาน ติดตั้งบนมือถือได้และใช้งานได้โดยไม่ต้องมีอินเทอร์เน็ต

- วิเคราะห์ธาตุ บุคลิก ด้านเด่น งานและอาชีพ
- ดวงรายปีและรายเดือน 2026–2050 ทั้งฝั่งตัวเองและฝั่งโลก
- 8 ด้าน: การงาน เงิน สุขภาพ ธุรกิจ ที่อยู่อาศัย เดินทาง ทอง หุ้น
- เพิ่มได้หลายคน สำรองและนำเข้าข้อมูลเป็นไฟล์

## ติดตั้งบนมือถือ
- iPhone: เปิดลิงก์ใน Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม
- Android: เปิดลิงก์ใน Chrome → ⋮ → ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก

## ข้อมูลส่วนตัว
วันเกิดที่กรอกเก็บในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่ได้ส่งขึ้นเซิร์ฟเวอร์หรือ GitHub

## หมายเหตุ
จัดทำขึ้นเพื่อเป็นศาสตร์ดูดวงพื้นฐาน ควรใช้วิจารณญาณในการอ่าน ไม่ใช่คำทำนายอนาคต ไม่ใช่คำแนะนำการลงทุน การแพทย์ หรือกฎหมาย

## ไฟล์
- `index.html` ตัวแอปทั้งหมด (ตัวคำนวณ + หน้าจอ) ในไฟล์เดียว
- `manifest.webmanifest`, `sw.js`, ไอคอน: สำหรับติดตั้งและใช้แบบออฟไลน์
